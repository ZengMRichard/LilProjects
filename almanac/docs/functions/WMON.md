# WMON · Watchlist monitor

Kind: market · Phase 0

## Usage

```
WMON [list]
```

## Arguments

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `list` | string | core | Watchlist name; a new name creates an empty list |

## Examples

- `WMON`
- `WMON list=core`
- `WMON list="My Tech"`

## Data

- Local state only.

Exports: csv, tsv

Keywords: watchlist, monitor, quotes, live, ticker
