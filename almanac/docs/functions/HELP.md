# HELP · Help and function search

Kind: tool · Phase 0

## Usage

```
HELP [q]
```

## Arguments

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `q` | string |  | A function code or words to search for |

## Examples

- `HELP`
- `HELP CHRT`
- `HELP yield`
- `HELP balance sheet`

## Data

- Local state only.
